# Hopsy 🎄🍻

Hopsy is a social pub crawl game app inspired by the Irish Christmas tradition,
12 Pubs of Christmas. Plan a night out with friends, explore pubs, and play group
challenges.

🚧 Under active development.

## Tech Stack

- **Mobile:** React Native, Expo, TypeScript
- **API:** Node.js, Fastify, TypeScript
- **Database & Auth:** Supabase PostgreSQL, Prisma, Supabase Auth
- **Monorepo:** pnpm Workspaces

## Getting Started

Use Node.js 24 (see `.nvmrc`) and pnpm.

```sh
pnpm install
```

Configure and run each app using its guide:

- [Mobile — `apps/mobile`](apps/mobile/README.md)
- [API — `apps/api`](apps/api/README.md)
